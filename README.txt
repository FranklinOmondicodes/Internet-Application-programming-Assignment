SAVANNA BREW CAFE — WEBSITE ASSIGNMENT
=====================================

Pages: index.html, about.html, menu.html, gallery.html, contact.html
Stylesheet: css/style.css
Images: images/ (original locally stored SVG illustrations and logo)

PREVIEW
1. Extract the ZIP.
2. Open the savanna-brew folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.
4. Test every navigation link and resize the browser to mobile width.

IMAGE NOTE
Original SVG illustrations are used instead of JPG photographs. This keeps all
images local, lightweight and available offline. Image paths are referenced
locally and each content image has meaningful alt text.

RESERVATION FORM LIMITATION
The form uses mailto and browser-native required/email validation. It depends
on an email application being configured. hello@savannabrew.example is a
fictional example address and will not deliver a real booking. Real booking
delivery requires a real café email address and a form service or server-side
backend; JavaScript is not used in this assignment.

VALIDATION
Please validate all five HTML pages at https://validator.w3.org/ and the CSS
at https://jigsaw.w3.org/css-validator/ before submission. External W3C
validation has not been run from this package. Record any remaining warnings
or errors here after checking.

SUBMISSION
Rename the ZIP to YourName_RegNo_Assignment1.zip using your own name and
registration number before submitting if required by your lecturer.
